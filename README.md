# 鍵雨

在瀏覽器裡練英文打字。介面是繁體中文，要打的內容是英文單字和句子。

有兩種玩法：

- **字雨**：單字從上方落下，在碰到紅線前把它們打完。打錯會斷連擊，愈接近地面才消去就有驚險加分。時間愈久，落得愈快。
- **競速**：六十秒限時。照順序打出畫面上的英文，空白也要打。簡單與普通不分大小寫；困難要連大小寫、逗號、句點和撇號都正確。

分數、速度（每分鐘字數）、準確率、連擊和命數（或剩餘時間）會即時顯示。每個模式和難度各自保留前六名，存在這台瀏覽器的 `localStorage`（鍵名 `keyfall-v1`）。

## 環境

需要 Node.js 20 以上。

## 啟動

```bash
npm install
npm run dev
```

然後打開 [http://127.0.0.1:47321](http://127.0.0.1:47321)。

## 建置

```bash
npm run build
npm run preview
```

`npm test` 會檢查計分、選字和題庫。

## 怎麼玩

開始前請把輸入法切到英文。

1. 用上下鍵選模式，左右鍵調難度，也可以直接按 `1` / `2` / `3`。
2. 按 Enter 開始。倒數時再按 Enter 可跳過。
3. 字雨：按第一個字母鎖定最靠近地面的那個單字，再把剩下的字母打完。不能用倒退鍵。
4. 競速：依序打出每個字元。打錯要訂正後才能繼續。
5. Esc 暫停。暫停時 Enter 繼續、R 重來、Q 回主選單。
6. 結束後 Enter 再來一局，Esc 回主選單。

音效可用右上角按鈕開關。選單和暫停時按 M，遊戲中按 F2。音效是瀏覽器即時合成的，沒有額外音檔。

清除這個網站的瀏覽器資料，就會一併清掉排行榜。
